# minerals/

Simulated Cu-Kα powder patterns for common minerals, generated by
[`scripts/simulate_references.py`](../../scripts/simulate_references.py) from textbook crystal
structures (space group, lattice constants and atomic positions) with pymatgen's XRDCalculator.
Gaussian peaks, FWHM 0.10° 2θ, 5–90° on a 0.01° grid, strongest peak = 100.

| File | Phase | Strongest reflections (° 2θ, Cu Kα) |
|---|---|---|
| calcite_CaCO3 | calcite | 29.42, 48.54, 47.55 |
| magnesite_MgCO3 | magnesite | 32.67, 43.03, 53.93 |
| dolomite_CaMg(CO3)2 | dolomite | 30.99, 41.19, 51.15 |
| siderite_FeCO3 | siderite | 32.05, 24.78, 52.91 |
| quartz_SiO2 | α-quartz | 26.66, 20.88, 42.49 |
| halite_NaCl | halite | 31.73, 45.49, 75.37 |
| sylvite_KCl | sylvite | 28.36, 40.55, 66.44 |
| periclase_MgO | periclase | 42.95, 62.35, 78.70 |
| lime_CaO | lime | 37.38, 53.90, 32.23 |
| brucite_Mg(OH)2 | brucite | 38.08, 18.62, 50.94 |
| portlandite_Ca(OH)2 | portlandite | 34.14, 18.06, 47.17 |

These are ideal patterns: no preferred orientation, no instrument profile, no Kα2. Real
measurements will differ in relative intensity (platy and fibrous phases especially) and peak
width. They are fine for screening which phases are present; for anything quantitative, measure
your own standards or use Rietveld.

**Adding phases** with large or hydrated cells (nesquehonite, hydromagnesite, dypingite,
lansfordite, gypsum, …): download the CIF from the
[Crystallography Open Database](https://www.crystallography.net/cod/), whose entries are in the
public domain, and run

```bash
python scripts/simulate_references.py --cif my_phase.cif --out reference_library/cod
```
